# ETF skill · Product policy (hard)

These rules override module convenience. Violations → `status: blocked` or rewrite narrative.

## Yield / return language

| Forbidden | Required instead |
|-----------|------------------|
| 保证 15%+ / guaranteed yield / 稳赚 / 必涨 | Expected **range** + uncertainty; historical is not promise |
| Treating distribution rate as total return | Explicit **distribution vs total return** split |
| Selling covered-call ETF as “safe income + upside” | Cap upside, possible NAV erosion, tax note if relevant |

Institutional long-horizon equity expected returns are typically **mid-single-digit to high-single-digit** annualized ranges in forward models — **not** a 15% guarantee. This product must not invent a higher “product yield guarantee.”

## Leverage

| Product class | Policy |
|---------------|--------|
| **Inverse / short** (SQQQ, SPXU, SPXS, …) | **Out of scope.** Refuse as investment recommendation path. User may still ask *what it is* → taxonomy only + “we do not plan inverse sleeves.” |
| **Levered long** (TQQQ, UPRO, SOXL, …) | **Tactical short-horizon only.** Not core. Not “hold forever.” Emphasize daily reset / path dependency. |
| Single-stock levered | Extra caution; no auto-order; stance only on the advice card |

## Income / covered-call ETFs

Allowed as **satellite research**. Always include:

1. Mechanism (sold upside)  
2. Distribution can exceed economic earnings  
3. Bull-market lag risk  
4. Not a substitute for broad-market total-return core unless user explicitly accepts lag
