# x-advanced-research · X 研究手艺（Grok Bot 版）

> **用途：** 给技能入口的 KOL routine / ad-hoc X 研究提供"怎么读 X、抽什么、怎么引用"的手艺。  
> **不负责：** 估值、陷阱定级、买卖判断、Verdict。这些在引擎其他模块与技能入口的决策表里。  
> **账号与预算：** 见技能入口 `references/contracts/accounts.md`；本文不保留账号名单，不保留 85 号表。

---

## 1. 读取方式

在 Grok Bot 上用内置 X 读取器（公开推文只读，不消耗 X API 额度）：

| 需要 | 读法 |
|------|------|
| 某账号最近推文 | 读该账号时间线（`from:@handle`），按时间倒序 |
| 某主题/代码讨论 | 关键词检索：`$TICKER`、公司名、产品名；可加时间窗与 `min_faves` 过滤 |
| 一条帖的完整上下文 | 打开帖子/线程（只读主帖与必要回复） |
| 账号是否存在/改名 | 账号解析，确认 handle 与显示名 |

**硬规则（省预算）：**
- 一个账号一轮 **1 次**时间线读取；只有正文被截断且可见部分含美股代码/明确多空句时，才补 1 次主帖读取。主账号一轮最多 **2 次**；补充 routine 一轮 **3–6 次**。
- 时间窗 = min(距上次成功运行, 14 天)；每个账号只保留**最新 8 条原始推文**，回复丢弃。
- 不扫这六个账号以外的时间线，除非用户点名 ad-hoc 研究。
- X 读取失败：写 `source_error`，说明失败；**不要用网页镜像替代原帖**。

## 2. 从帖子里抽什么（只抽事实，不做判断）

每条保留：

```text
handle, url, posted_at, text(原文，可截断但不得改写), lang,
symbols[]（帖中出现的可解析美股代码/公司名）,
ask_or_claim（作者原句中的主张，原文引用）,
conviction_hint（high|mid|low|none，仅按原句判断：
  high=有机制/数字/时间窗；mid=只有方向；low=只出现代码；none=无该票）,
paid_or_promo（是否含付费群/邀请链接/推广，bool）
```

规则：
- 只抽帖子里**真实出现**的代码/公司名；不补全、不猜测、不把宏观闲聊硬映射成票。
- 作者给出的目标价、仓位只作**原句引用**，永远不作为建议卡的目标价。
- 非美股（A/HK/加密等）直接丢弃该条；**不要因为一条非美股帖中止整轮**。
- 重复贴（同链接）、纯回复、纯转发无评论：丢弃；同一代码同一天多条只留信号最强的一条并记录条数。

## 3. 候选与排序（交给技能入口）

按下面顺序给技能入口一个候选清单（上限 15 只，实际出卡由入口按 N≤2 控制）：

1. 主账号原句里带机制/数字/时间窗的票；
2. 多个账号（≥2）在同一窗口提到的票；
3. 补充账号单独提到、且主账号没写过的票（标 `source: supplement`）；
4. 其余只出现代码、无机制的票放"观察"。

输出字段（技能入口据此组数据包并决定要不要送分析）：

```text
symbol, source(primary|supplement), handles[], mentions_14d, accounts_14d,
quotes[]（原句 + 链接 + 时间）, conviction_hint, risk_flags[]
```

---

## 4. 证据等级（与 Sherlock §1.4 对齐）

- X 社交整体**最多算 1 条证据链**；纯社交方向判断 **≤ C**。
- 付费订阅源、喊单话术、无出处截图：只算**观点**，不算独立证据。
- 帖子里没有可核对的机制/数字/文件：不要拔高为"强信号"。

---

## 5. ad-hoc X 研究（用户点名时）

用户点名叫"用 X 查 XX / 看看谁在说 XX / Serenity 风格扫描"时：

- 可以扩大到 8–15 次读取，但每次读取都要有明确目的（账号/关键词/线程）；
- 结果按主题聚合、每帖带链接；不写买卖建议；
- 需要更深的估值/陷阱，交回技能入口决定是否调用引擎其他模块。

---

## 6. 禁止

- 不打开 Balder / Serenity / Koltracker 等第三方网站；不把网站内容当 X 原帖。
- 不编造帖子、链接、作者、时间、目标价。
- 不做"卡点评分""瓶颈排名"（那是 serenity 模块的事，且只在用户点名时）。
- 不调用其他引擎模块；不做交易执行。
