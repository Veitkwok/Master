## 1. 核心概念：相对历史便宜度（不是内在价值）

### 1.1 定义

对某一标的、某一估值指标的时间序列 \(v_t\)（如月末 PE-TTM）：

1. 取窗口：默认最近 **10 年** 有效观测（建议 **月末** 采样以降噪）。  
2. 样本集 \(S = \{v_t\}\)，经清洗规则（§1.3）。  
3. 分位线：  
   - \(L_{20} = \mathrm{Percentile}(S, 20)\)  
   - \(L_{50} = \mathrm{Percentile}(S, 50)\)  
   - \(L_{80} = \mathrm{Percentile}(S, 80)\)  
4. **当前分位点**（「现在在历史什么位置」）：  

\[
p = \frac{\#\{v_i \le v_{\mathrm{now}}\}}{|S|}
\]

（实现时可改用线性插值分位；文档层只要求**可复现、写死一种**。）

### 1.2 四区间与默认动作（PE/PB 等「越高越贵」）

| 条件 | 区间标签 | 默认研究动作（非交易指令） |
|------|----------|---------------------------|
| \(v < L_{20}\) 或 \(p < 0.20\) | **低估** | 主收集区：可用剩余月度 envelope 做下跌触发加仓框架 |
| \(L_{20} \le v < L_{50}\) | **合理偏低** | 可补偿性建仓 / 慢速建仓；优先级低于低估 |
| \(L_{50} \le v < L_{80}\) | **合理偏高** | **只持有，不加仓**（研究默认） |
| \(v \ge L_{80}\) | **高估** | 分批减仓 / 不再新开；卫星可提前收缩 |

**严格门闩（可选、更保守）：** 仅在 \(p \le 0.20\) 开始新资金；\(0.20 < p \le 0.50\) 仅允许「补偿性」小份；\(p > 0.50\) 零新资金。

### 1.3 语义翻转指标（越高越便宜）

适用于：**股息率（DY）**、**股债利差 / ERP 类「利差越大股票越便宜」** 的定义（以指标文档为准）。

| 条件（翻转后） | 区间标签 | 说明 |
|----------------|----------|------|
| \(v > L_{80}\) 或 \(p > 0.80\) | **低估**（便宜） | 色带/区间语义与 PE **上下颠倒** |
| \(L_{50} < v \le L_{80}\) | 合理偏低 | |
| \(L_{20} < v \le L_{50}\) | 合理偏高 | |
| \(v \le L_{20}\) | **高估**（贵） | |

配置字段建议：`invert_bands: true`。

### 1.4 样本清洗（写死，避免静默污染）

| 规则 | 处理 |
|------|------|
| PE ≤ 0 或极端巨无（实现时设上限，如 >500） | **剔除**该点，或整段标 `metric_invalid` |
| 指标缺失日 | 跳过；不插值冒充 |
| 指数成分大调仓日 | 可保留点，但报告中标注「调仓可能跳变」 |
| 窗口内有效点过少（如 < 36 个月） | **降低可靠性**；禁止宣称「标准 10 年分位」 |

### 1.5 认识论红线（Sherlock）

| 允许说 | 禁止说 |
|--------|--------|
| 「相对近 10 年历史偏便宜 / 偏贵」 | 「低估 = 内在价值安全」「长期不可能亏」 |
| 「分位法是纪律尺，非定价模型」 | 「估值曲线与点位一模一样故必赚」 |
| 「regime 变化可使分位失真」 | 「数万人验证 = 统计有效」 |

**美股尤甚：** 利率体制切换、Magnificent 7 权重上升、指数方法论变更，都会让「10 年分位」的解释力下降。报告必须允许 **regime 注释** 与 **可靠性降级**。

## 2. 指标选择决策树（可编码）

### 2.1 决策树

```text
0) 产品是否在投资路径红线内？
   - 反向 / 做空 ETF → 不做投资路径（taxonomy only）
   - 杠杆多头 → 不做 10 年估值主体系；短线战术另册（M6）
   - Covered-call / 高分配结构 → 禁止用「分配率」当分位便宜度
     → 改：总回报、溢价/折价、cap 风险、收入诚实（M5）

1) 是否债券 / 商品 / 纯宏观工具 ETF？
   - 债券：到期收益率 / 利差框架（另建；勿套股票 PE 分位）
   - 黄金/原油等：宏观 / 实际利率；不套股票估值分位主体系

2) 成分盈利是否大体为正、利润波动是否温和？
   - 是 → primary: PE-TTM 或 Forward PE；secondary: PB 或 DY
   - 否 / 强周期 → primary: PB 或周期调整/常态化盈利指标；secondary: PE 或 EV/Sales

3) 产品是否以「稳定分红」为主要卖点（宽基红利类）？
   - 是 → primary: DY（invert_bands=true）；secondary: PE
   - 分红潮 / 特殊分红可疑 → 强制主辅交叉；DY 单独不决策

4) 需要全市场 risk-on/off 辅线？
   - 宽基（SPY/VOO/VTI）可用 ERP / 股债利差作 secondary 宏观辅线
   - 单一行业 ETF：ERP 权重低，勿主导

5) 输出：primary_metric, secondary_metric, invert_bands, reliability_notes
```

### 2.2 「学会选指标」的操作步骤（给 AI / 人）

1. 读 ETF 画像：指数方法论、行业、杠杆/备兑结构、分红政策。  
2. 用 §2.1 树选出 primary + secondary + invert 标志。  
3. （以后）拉历史序列 → 算分位 → 写入 `universe` 配置。  
4. 人工抽检：与公开分位站 / 发行商数据对照 1–2 锚点。  
5. 每年或重大指数重构 / 利率 regime 切换后复审 primary。

| 标的类型 | 例 | primary | secondary | invert | 备注 |
|----------|-----|---------|-----------|--------|------|
| 宽基大盘 | SPY, VOO, IVV | pe_ttm 或 pe_forward | erp 或 dy | false | 利率 regime 变化时分位需注释 |

## 3. 与「4% 定投」纪律的映射（改写版）

### 3.1 原文「1+1+4」压缩

| 块 | 原文要点 | 本文采纳？ |
|----|----------|------------|
| 目标 | 优先指数；>7 年；业绩尽量稳 | **采纳并美股化**（§3.2） |
| 前提 | 只在合理估值内买；高估回避 | **采纳**（§1.2 门闩） |
| 4% | 相对上一买点每再跌 4% 触发一笔 | **采纳为节奏模板**，金额改写（§3.3） |
| 仓位 | 单标的 ≤40% 总仓；拆 10 份 | **软参考**；小 envelope 用份数优先 |
| 卖出 | 高估分批卖 | **研究框架采纳**；非自动下单 |
| 话术 | 注定成功 / 只亏时间 | **禁止** |

### 3.2 目标筛选（美股 ETF）

| 准则 | 要求 | 可靠性影响 |
|------|------|------------|
| 上市/指数历史 | 尽量 ≥7–10 年可观测 | 不足则分位 **降级** |
| 结构 | 非反向；杠杆不进核心分位体系 | 红线 |
| 盈利/指数质量 | 宽基或业绩相对稳的行业优先作「核心纪律标的」 | 强周期可投但换 PB 等 |
| 分配结构 | 备兑高分配 → 收入诚实路径，不进 DY 低估主体系 | 红线 |
| 用户目标 | 核心 β / 卫星 / 战术 角色先定，再套分位 | 与 M4 对齐（未来） |

### 3.3 触发节奏：4% → 主人本轮说出的现金切片

金额不在本文件。已有持仓读技能入口的数据包契约。新买的金额只在主人本轮说出现金数字之后，由建议卡契约收口。不要使用历史的月度 600–1000 上限。个股信号明确时，ETF 新买可以延后。普跌时可以提高 ETF 占比。这两句不发明金额。

**可执行框架（不是订单）：**

```text
若主人本轮没有说出可投现金: 不写金额
remaining = 主人本轮说出的现金 − 本轮已经建议的新买
if remaining <= 0: 不再新开 ETF

对某候选 ETF E:
  if 估值门闩不满足（如 p > 0.50）: 不加仓
  if 杠杆/反向/红线: 停止
  if 触发条件:
       a) 相对 E 的 last_buy_price 再跌 ≥ 4%，或
       b) 首次建仓且处于低估/合理偏低 且 用户确认角色需要
     then size = min( remaining / N_slices_left , remaining )
          记录「可部署 size」；N 默认 5–10
```

| 参数 | 建议默认 | 说明 |
|------|----------|------|
| `drop_trigger_pct` | 4% | 相对上一研究买点；可调 3–5% |
| `N_slices` | 5–10 | 只切主人本轮说出的 remaining |
| `single_etf_month_cap` | ≤ remaining 的 50–100% | 小账户不必教条 40% 总资产；**总资产 40%** 作中长期软顶 |
| `p_max_for_new_cash` | 0.50（严：0.20） | 与 §1.2 一致 |

**禁止改写成：**

- 「把一笔主人没说的金额投满某 ETF」  
- 「子弹打光后只亏时间不亏钱」  
- 「保证回本 / 注定成功」  

### 3.4 兼容 / 冲突总表

| 主题 | 兼容？ | 处理 |
|------|--------|------|
| 低估加、高估减、中间少动 | ✅ | 直接进纪律叙述 |
| 估值分位门闩 | ✅ | §1；数据未就绪时 = 手动/半自动 |
| 4% 下跌触发 | ✅ 改写 | 触发保留；金额 = 剩余 envelope 切片 |
| 固定 10 份打光某标的 | ⚠️ | 改为动态 `N_slices` + 月度 remaining |
| 单标的 40% 总仓 | ⚠️ | 中长期软顶；月额 $1k 场景优先「本月 remaining」 |
| 个股优先吃额度 | ✅ 我方政策 | ETF 为 residual；与「普跌多 ETF」并列 |
| 主动基金用大盘估值代理 | ⚠️ 低优先 | 美股主动/半透明产品另议；非本阶段 |
| 保证收益修辞 | ❌ | 永久禁止进 skill |
| 公众号日报当真源 | ❌ | 自建 lab / 人工校准 |

## 9. 一页纸备忘

1. **三条线** = 窗口内估值序列的 20/50/80 分位水平线 → 四区间。  
2. **尺子** = 相对历史便宜度；美股要写 regime 风险。  
3. **选指标** = 稳→PE；周期→PB；红利→DY（翻转）；备兑/杠杆/反向另册。  
4. **QQQ** → 主 PE（TTM/Forward），不宜主 PB。  
5. **4%** → 下跌触发保留；金额 = **剩余月度 envelope / 份数**；个股可优先吃额度。  
6. **永不写入 product：** 保证收益、粉丝证明、无数据假分位、分配率当便宜度。
